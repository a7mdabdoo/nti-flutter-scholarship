# 📱 ملخص الجلسة الرابعة (Session 04)

> **المحاضر:** م / إبراهيم حمادة مسعد  
> **الموضوع:** الحلقات التكرارية (`for` loop)، التحكم بـ `break` و `continue`، والدوال البرمجية (`Functions`).

---

## 1. الحلقات التكرارية (`for` Loop)

تُستخدم لتكرار تنفيذ كود معين عدد محدد من المرات بدلاً من كتابته يدوياً:

* **طريقة كتابتها:**
  1. **نقطة البداية (Initialization):** مثل `int i = 1`
  2. **شرط الاستمرار (Condition):** مثل `i <= 5`
  3. **مقدار التغيير (Increment/Decrement):** مثل `i++`

### التحكم في اللوب: الفرق بين `break` و `continue`

| الأمر | الوظيفة | متى نستخدمه؟ |
|:---:|:---|:---|
| **`break`** | **إيقاف وكسر اللوب بالكامل** والخروج منه فوراً. | عندما نجد العنصر الذي نبحث عنه ولا نحتاج لإكمال باقي اللفات. |
| **`continue`** | **تخطي اللفة الحالية فقط** والانتقال للفة التالية. | عندما نريد تجاهل رقم أو حالة معينة مع استمرار اللوب لآخره. |

<div dir="ltr">

```dart
void main() {
  for (int i = 1; i <= 6; i++) {
    if (i == 2) {
      continue; // تخطي الرقم 2 فقط وكمّل اللوب
    }
    if (i == 5) {
      break; // أوقف اللوب تماماً عند الوصول للرقم 5
    }
    print('Number: $i'); // سيطبع: 1, 3, 4
  }
}
```

</div>

## 2. الدوال البرمجية (`Functions`)

الدالة هي بلوك من الكود له اسم محدد، يُكتب مرة واحدة ويمكن استدعاؤه وتكراره في أي مكان في البرنامج.

### طريقة كتابة الـ Function:
1. **نوع القيمة المرجعة (`Return Data Type`):** مثل `int`, `String`, أو `void`.
2. **اسم الدالة (`Function Name`):** يُكتب بأسلوب `camelCase` يوضح وظيفتها.
3. **الأقواس والمدخلات (`Parameters`):** `(int x, int y)`
4. **جسم الدالة (`{ Code }`) وأمر الإرجاع (`return`).**

<div dir="ltr">

```dart
// تعريف الدالة
int sumThreeNumbers(int x, int y, int z) {
  return x + y + z;
}

void main() {
  // استدعاء الدالة داخل الـ main
  int result = sumThreeNumbers(10, 20, 30);
  print('Sum = $result'); // 60
}
```

</div>

## 3. الفرق بين `Parameters` و `Arguments`

| المصطلح | مكانه | الشرح والمثال |
|:---:|:---|:---|
| **`Parameters` (المعاملات)** | عند **إنشاء وتعريف الدالة** بين الأقواس `()`. | هي أسماء المتغيرات المستقبِلة: `(int x, int y, int z)` |
| **`Arguments` (القيم الممررة)** | عند **استدعاء الدالة** داخل الـ `main`. | هي القيم الفعلية الحقيقية المرسلة للدالة: `(10, 20, 30)` |

---

## 4. ما هي فائدة استخدام الـ Functions؟

1. **تبسيط الكود (`More Simple`):** تقسيم المشكلة الكبيرة إلى مهام صغيرة بسيطة ومستقلة.
2. **تنظيم البرنامج (`More Organized`):** فصل كل وظيفة في دالة خاصة بدلاً من تكديس كل الأكواد في `main`.
3. **سهولة القراءة (`More Readable`):** يجعل الكود مفهوماً وواضحاً لأي مبرمج يقرؤه.
4. **سهولة الصيانة والإدارة (`Better Management`):** لو أردت تعديل معادلة، تعدلها في الدالة مرة واحدة فقط بدلاً من البحث عنها في كل البرنامج (منع تكرار الكود).
5. **الأمان والعزل (`More Secure`):** متغيرات الدالة تكون محلية ومعزولة (Local Scope) فلا تتأثر أو تُفسد باقي متغيرات البرنامج.

---

## 5. الفرق بين `void` Function والدوال ذات النوع (`Return Type`)

| وجه المقارنة | دالة `void` | دالة بنوع بيانات (`int`, `String`, `double`...) |
|:---|:---|:---|
| **القيمة المُرجعة** | **لا تُرجع أي قيمة**، بل تنفذ أمراً مباشراً فقط (مثل الطباعة). | **لازم تُرجع قيمة** باستخدام كلمة `return` من نفس نوع الدالة. |
| **استخدام الناتج** | لا يمكن تخزينها في متغير. | يمكن تخزين ناتجها في متغير أو استخدامها في عمليات أخرى. |

<div dir="ltr">

```dart
// 1. دالة void: تطبع فقط ولا ترجع قيمة
void sayHello(String name) {
  print('Hello, $name!');
}

// 2. دالة لها نوع إرجاع (int): تحسب وترجع قيمة لنستخدمها
int multiply(int a, int b) {
  return a * b;
}

void main() {
  sayHello('Ahmed');           // تنفيذ مباشر
  int total = multiply(5, 4);  // استقبال القيمة الراجعة في متغير
  print('Total = $total');
}
```
