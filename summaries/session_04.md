## 1. الحلقات التكرارية: For Loop

تُستخدم لتكرار تنفيذ كود معين عدد محدد من المرات بدلاً من كتابته يدوياً.

| الجزء | الاسم بالإنجليزية | الوظيفة | مثال |
|:---|:---|:---|:---|
| **1. نقطة البداية** | Initialization | تحديد بداية العداد | `int i = 1` |
| **2. شرط الاستمرار** | Condition | يستمر اللوب طالما الشرط صحيح | `i <= 5` |
| **3. مقدار الزيادة** | Increment | تحديث العداد بعد كل لفة | `i++` |

### التحكم في اللوب: الفرق بين Break و Continue

| الأمر | الوظيفة | متى نستخدمه؟ |
|:---:|:---|:---|
| **`break`** | إيقاف وكسر اللوب بالكامل والخروج منه فوراً | عندما نجد العنصر المطلوب ولا نحتاج لإكمال باقي اللفات |
| **`continue`** | تخطي اللفة الحالية فقط والانتقال للفة التالية | عندما نريد تجاهل رقم أو حالة معينة مع استمرار اللوب لآخره |

</div>

```dart
void main() {
  for (int i = 1; i <= 6; i++) {
    if (i == 2) {
      continue; // Skip number 2 and continue loop
    }
    if (i == 5) {
      break; // Stop the loop completely at 5
    }
    print('Number: $i'); // Output: 1, 3, 4
  }
}
```

## 2. الدوال البرمجية: Functions

الدالة هي بلوك من الكود له اسم محدد، يُكتب مرة واحدة ويمكن استدعاؤه وتكراره في أي مكان في البرنامج.

### أجزاء كتابة الدالة:

| الترتيب | الجزء | الوصف | مثال في الكود |
|:---:|:---|:---|:---|
| **1** | **نوع الإرجاع (Return Type)** | نوع القيمة التي سترجعها الدالة | `int`, `String`, `void` |
| **2** | **اسم الدالة (Function Name)** | اسم يعبر عن وظيفة الدالة | `sumThreeNumbers` |
| **3** | **المدخلات (Parameters)** | المتغيرات التي تستقبلها الدالة بين القوسين | `(int x, int y, int z)` |
| **4** | **جسم الدالة (Body & Return)** | الكود المراد تنفيذه وإرجاع الناتج | `{ return x + y + z; }` |

</div>

```dart
// 1. Function Definition
int sumThreeNumbers(int x, int y, int z) {
  return x + y + z;
}

void main() {
  // 2. Calling the Function in main
  int result = sumThreeNumbers(10, 20, 30);
  print('Sum = $result'); // Output: 60
}
```

## 3. الفرق بين Parameters و Arguments

| المصطلح | مكانه في الكود | الشرح | مثال |
|:---|:---|:---|:---|
| **Parameters (المعاملات)** | عند تعريف وإنشاء الدالة | هي المتغيرات المستقبِلة للبيانات | `int x, int y, int z` |
| **Arguments (القيم الممررة)** | عند استدعاء الدالة داخل `main` | هي القيم الفعلية الحقيقية المرسلة للدالة | `10, 20, 30` |

---

## 4. ما هي فائدة استخدام الدوال؟

| الفائدة | المصطلح | الشرح |
|:---|:---|:---|
| **1. التبسيط** | More Simple | تقسيم المشكلة الكبيرة إلى مهام صغيرة بسيطة ومستقلة |
| **2. التنظيم** | More Organized | فصل كل وظيفة في مكان مستقل بدلاً من تكديس الكود في `main` |
| **3. سهولة القراءة** | More Readable | جعل الكود واضحاً ومفهوماً لأي مبرمج يقرؤه |
| **4. سهولة الصيانة** | Better Management | تعديل الكود في مكان واحد فقط بدلاً من تكراره في كل البرنامج |
| **5. الأمان والعزل** | More Secure | متغيرات الدالة محلية ومعزولة ولا تتداخل مع باقي البرنامج |

---

## 5. الفرق بين دالة Void والدوال ذات النوع

| وجه المقارنة | دالة `void` | دالة بنوع بيانات (`int`, `String`, `double`) |
|:---|:---|:---|
| **إرجاع القيم** | لا تُرجع أي قيمة، بل تنفذ أمراً مباشراً فقط مثل الطباعة | يجب أن تُرجع قيمة باستخدام `return` من نفس نوع الدالة |
| **تخزين الناتج** | لا يمكن تخزينها في متغير | يمكن تخزين ناتجها في متغير واستخدامه في عمليات أخرى |

</div>

```dart
// 1. Void function: executes code without returning a value
void sayHello(String name) {
  print('Hello, $name!');
}

// 2. Return-type function: calculates and returns an int value
int multiply(int a, int b) {
  return a * b;
}

void main() {
  sayHello('Ahmed');
  int total = multiply(5, 4);
  print('Total = $total'); // Output: 20
}
```
