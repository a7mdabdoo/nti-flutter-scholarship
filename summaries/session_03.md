## 1. الفرق بين `var` و `dynamic` ومميزاتهم

| وجه المقارنة | `var` | `dynamic` |
|:---|:---|:---|
| **الفكرة الأساسية** | ليست نوع بيانات، بل كلمة تجعل Dart **تستنتج النوع تلقائياً** من أول قيمة. | نوع مرن يقبل **أي نوع بيانات** ويمكن تغييره في أي وقت. |
| **تغيير النوع لاحقاً** | ❌ **غير مسموح** (بمجرد أخذ نص يظل `String` للأبد). | ✅ **مسموح** (ممكن يبدأ برقم ثم يتحول لنص أو `bool`). |
| **وقت الفحص** | يُفحص في الـ **Compile Time**. | يُفحص في الـ **Run Time**. |
| **المميزات والاستخدام** | كود مختصر + أمان عالي + دعم الإكمال التلقائي (Autocomplete). | مرونة عالية عند استقبال بيانات غير معروفة النوع مسبقاً (مثل الـ API / JSON). |

<div dir="ltr">

```dart
var city = 'Cairo';
// city = 100; // ❌ Error: لا يمكن تغيير النوع بعد استنتاجه

dynamic data = 100;
data = 'Hello Dart'; // ✅ مسموح بتغيير النوع
```

</div>

## 2. الفرق بين `Compile Time` و `Run Time`

* **وقت الترجمة (Compile Time):**
  - هي مرحلة **قبل تشغيل البرنامج**، يقوم فيها المترجم (Compiler) بفحص الكود، والتأكد من صحة القواعد (Syntax) وأنواع البيانات، وتحويل الكود إلى لغة الآلة.
* **وقت التشغيل (Run Time):**
  - هي مرحلة **عمل البرنامج الفعلي** على الجهاز، وتفاعل المستخدم معه وتنفيذ الأوامر في الذاكرة (RAM).
* **🎯 ما هي النقطة الفاصلة بينهما؟**
  - النقطة الفاصلة هي **لحظة بدء تشغيل البرنامج ودخول المعالج لتنفيذ دالة `main()`**؛ قبلها هو كود ثابت يُفحص ويُترجم، وبعدها هو برنامج حي يعمل ويتفاعل مع المدخلات.

## 3. الفرق بين `final` و `const`

كلاهما يُستخدم لتعريف **ثوابت لا يمكن تغيير قيمتها بعد إسنادها أول مرة**، لكن الفرق الجوهري في **متى تُعرف القيمة**:

| المقارنة | `const` | `final` |
|:---|:---|:---|
| **وقت تحديد القيمة** | **Compile Time** (قبل تشغيل البرنامج). | **Run Time** (أثناء تشغيل البرنامج). |
| **متى نستخدمه؟** | للقيم الثابتة المعروفة مسبقاً (مثل `pi = 3.14`). | للقيم التي لن نعرفها إلا وقت التشغيل (مثل وقت فتح التطبيق أو بيانات قادمة من المستخدم). |

<div dir="ltr">

```dart
const double pi = 3.14159;           // ✅ معروفة قبل التشغيل
final DateTime now = DateTime.now(); // ✅ تتحدد لحظة تشغيل البرنامج فقط
```

</div>

## 4. دمج المتغيرات في النصوص (String Interpolation)

طريقة كتابة المتغيرات أو العمليات البرمجية مباشرة داخل النص بدلاً من استخدام علامة `+`:
1. **لدمج متغير واحد:** نضع علامة `$` قبل اسم المتغير: `'Hello $name'`
2. **لدمج عملية حسابية أو خاصية:** نضعها داخل `${}`: `'Next year: ${age + 1}'`

<div dir="ltr">

```dart
String name = 'Ahmed';
int age = 20;

print('My name is $name');
print('Next year my age will be ${age + 1}');
```

</div>

## 5. الإدخال والتحويل بين الأنواع (Input & Type Conversion)

لأن أي إدخال من المستخدم عبر `stdin.readLineSync()` يكون نوعه نص (`String`)، نحتاج لتحويله عند التعامل مع الأرقام:

* **من نص إلى رقم صحيح (`int`):** `int.parse('25')`
* **من نص إلى رقم عشري (`double`):** `double.parse('99.5')`
* **من رقم إلى نص (`String`):** `100.toString()`
* **التحويل الآمن (`tryParse`):**
  - يُستخدم عندما لا نضمن أن المستخدم أدخل رقماً صحيحاً.
  - لو المستخدم كتب حروفاً مثل `'abc'`، الدالة `int.tryParse('abc')` تُرجع `null` بدلاً من إيقاف البرنامج بـ Error!

<div dir="ltr">

```dart
String ageText = '25';
int age = int.parse(ageText);

String invalidInput = 'abc';
int? safeResult = int.tryParse(invalidInput); // النتيجة: null بدون Crash
```

</div>

## 6. معاملات الأمان من القيم الفارغة (Null-aware Operators)

في Dart، المتغير العادي لا يقبل `null` إلا إذا وضعنا علامة `?` بعد نوعه (مثل `String?`). للتعامل الآمن معه نستخدم:

| المعامل | اسمه | وظيفته ومثاله |
|:---:|:---|:---|
| **`?`** | **Nullable Type** | يسمح للمتغير بأن يحمل قيمة `null` (`String? username;`). |
| **`??`** | **If-Null Operator** | يعطي قيمة بديلة إذا كان المتغير `null` (`username ?? 'Guest'`). |
| **`??=`** | **Null-aware Assignment** | يضع قيمة داخل المتغير **فقط إذا كان فارغاً (`null`)** حالياً (`nickname ??= 'User'`). |
| **`?.`** | **Null-aware Access** | يصل لخاصية المتغير بأمان فقط لو لم يكن `null` (`username?.length`). |
| **`!`** | **Null Assertion** | يخبر المترجم على مسؤوليتك أن القيمة الآن **ليست `null` بالتأكيد** (`email!.length`). |

<div dir="ltr">

```dart
String? username;

// 1. استخدام ?? لإعطاء قيمة افتراضية
String displayName = username ?? 'Guest'; // النتيجة: Guest

// 2. استخدام ??= لإسناد قيمة إذا كان المتغير null
username ??= 'Ahmed'; // أصبح الآن Ahmed

// 3. استخدام ! عندما نكون متأكدين أنه ليس null
print(username!.length); // النتيجة: 5
```
