# 📱 ملخص الجلسة الثانية (Session 02)

> **المحاضر:** م / إبراهيم حمادة مسعد  
> **الموضوع:** أساسيات البرمجة، لغة Dart، المتغيرات، المعاملات (Operators)، الشروط، والإدخال (User Input).

---

## 1. ما هي البرمجة؟ (What is Programming?)
البرمجة هي أحد فروع العلوم الهندسية (**Software Engineering**)، هدفها الأساسي هو **حل المشكلات (Problem Solving)** وأتمتة المهام اليومية باستخدام الحاسوب.
* **كيف حلت البرمجة مشاكل العالم؟**
  - **الطب:** أجهزة الأشعة، تشخيص الأمراض بالذكاء الاصطناعي، وإدارة المستشفيات.
  - **التعليم:** المنصات التعليمية والتعلم عن بُعد.
  - **التواصل والتجارة:** تطبيقات المحادثات، والتجارة الإلكترونية، والدفع الإلكتروني.

---

## 2. أمثلة على مجالات البرمجة (Programming Fields)
1. **تطوير تطبيقات الموبايل (Mobile App Development):** زي ما بنتعلم بـ **Flutter** لبناء تطبيقات Android و iOS بكود واحد.
2. **تطوير مواقع الويب (Web Development):** بناء المواقع (Frontend للواجهات و Backend لقواعد البيانات والسيرفرات).
3. **الذكاء الاصطناعي وتعلم الآلة (AI & Machine Learning):** تحليل البيانات والتنبؤات وصناعة نماذج الذكاء الاصطناعي.
4. **الأنظمة المدمجة (Embedded Systems):** برمجة الرقائق الإلكترونية والسيارات والأجهزة الذكية (IoT).
5. **تطوير الألعاب (Game Development):** بناء ألعاب الفيديو عبر محركات مثل Unity و Unreal Engine.
6. **الأمن السيبراني (Cybersecurity):** حماية الأنظمة والشبكات من الاختراقات.

---

## 3. لماذا نستخدم لغات البرمجة؟
* **الآلة (Computer / Machine):** لا تفهم سوى لغة واحدة تسمى **اللغة الثنائية (Binary Code)** المكونة من `0` و `1`، وتتميز بالسرعة الفائقة جداً في معالجة ملايين العمليات في الثانية مقارنة بالإنسان.
* **لغة البرمجة (Programming Language):** هي لغة وسيطة يفهمها الإنسان (تحتوي على كلمات إنجليزية زي `if`, `while`, `print`)، وتتحول عبر **المترجم (Compiler / Interpreter)** إلى لغة تفهمها الآلة (`0, 1`).

---

## 4. ما هو Dart SDK؟
* اختصار لـ **Software Development Kit** (حزمة تطوير البرمجيات).
* هي الحزمة الكاملة اللي بتنزلها عشان تشغل وتطور لغة Dart، وبتحتوي على:
  1. **Dart VM & Compiler:** المترجم اللي بيحول كودك إلى لغة الآلة.
  2. **Core Libraries:** المكتبات الأساسية الجاهزة (زي `dart:core`, `dart:io`, `dart:math`).
  3. **Developer Tools:** أدوات فحص وتنسيق الكود (Dart Analyzer & Formatter).

---

## 5. المتغيرات والأنواع (Data Types & Type Systems)

### أنواع اللغات من حيث تحديد نوع البيانات:
1. **Static Typed Languages:** لازم تحدد نوع المتغير مسبقاً قبل التشغيل، والنوع ثابت لا يتغير (زي C++ و Java).
2. **Dynamic Typed Languages:** مش بتحدد نوع المتغير، والنوع بيتحدد تلقائياً وقت التشغيل (زي Python و JavaScript).
3. **لغة Dart (تجمع بين القوة والمرونة):**
   - لغة Dart في أصلها **Statically Typed** (تحافظ على أمان الكود وسرعته).
   - لكنها بتدعم **استنتاج النوع (Type Inference)** باستخدام كلمة `var`؛ يعني بتكتشف نوع البيانات لوحدها:
     ```dart
     var name = "Ahmed"; // Dart عرفت إنها String تلقائياً
     var age = 19;        // Dart عرفت إنها int تلقائياً
     ```
   - ولو عايز تحدد النوع بنفسك صراحة:
     - نصوص: `String`
     - أرقام صحيحة: `int`
     - أرقام عشرية: `double`
     - قيم منطقية: `bool` (صح أو خطأ `true / false`)
   - ولو عايز متغير يقبل أي نوع ويتغير في أي وقت بتستخدم `dynamic`.

## 6. المعاملات في Dart (Operators)

| النوع | المعاملات | الشرح والمثال |
|:---|:---|:---|
| **الحسابية (Arithmetic)** | `+`, `-`, `*`, `/`, `~/`, `%` | الجمع، الطرح، الضرب، القسمة، `~/` (قسمة صحيحة بدون كسور)، `%` (باقي القسمة). |
| **التعيين والإسناد (Assignment)** | `=`, `+=`, `-=`, `*=`, `/=` | إسناد وتعديل القيمة، مثلاً `x += 5` تعني `x = x + 5`. |
| **المقارنة (Comparison)** | `==`, `!=`, `>`, `<`, `>=`, `<=` | للمقارنة بين قيمتين والنتيجة دايماً `true` أو `false`. |
| **المنطقية (Logical)** | `&&` (AND), `\|\|` (OR), `!` (NOT) | الربط بين الشروط؛ `&&` يلزم تحقق الشرطين، `\|\|` يكفي تحقق شرط واحد، `!` لعكس القيمة. |

## 7. جمل التحكم والشروط (Conditions - if / else)

تستخدم لاتخاذ القرارات في البرنامج بناءً على الشروط:

```dart
if (الشرط) {
  // كود يتنفذ لو الشرط صح (true)
} else if (شرط آخر) {
  // كود يتنفذ لو الشرط الأول خطأ والثاني صح
} else {
  // كود يتنفذ لو كل الشروط السابقة كانت خطأ
}
```

---

## 8. طريقة الإدخال في Dart (User Input - بديل cin في C++)

في C++ بنستخدم `cin >> x;`، أما في **Dart**:

1. بنستورد مكتبة الإدخال والإخراج في أول الملف:
   ```dart
   import 'dart:io';
   ```
2. بنستخدم الدالة `stdin.readLineSync()!` لاستقبال نص من المستخدم من الـ Terminal.
3. **ملاحظة مهمة:** الدالة دي دايماً بترجع نص (`String?`)، فلو عايزين رقم لازم نعمل له تحويل (**Parsing**):
   - تحويل لرقم صحيح: `int.parse(stdin.readLineSync()!)`
   - تحويل لرقم عشري: `double.parse(stdin.readLineSync()!)`
   *(علامة `!` هي Null Assertion بتأكد للغة إن المستخدم هيدخل قيمة ومش هتكون فاضية).*

---

## 9. مثال شامل بلغة Dart (يجمع كل مفاهيم اليوم)

<div dir="ltr">

```dart
import 'dart:io';

void main() {
  // طلب إدخال اسم الطالب ودرجته
  stdout.write("Enter your name: ");
  String name = stdin.readLineSync()!;

  stdout.write("Enter your score (0 - 100): ");
  double score = double.parse(stdin.readLineSync()!);

  // فحص الدرجة وتحديد التقدير
  String grade;
  if (score >= 85 && score <= 100) {
    grade = "A (Excellent)";
  } else if (score >= 75) {
    grade = "B (Very Good)";
  } else if (score >= 65) {
    grade = "C (Good)";
  } else if (score >= 50) {
    grade = "D (Pass)";
  } else {
    grade = "F (Failed)";
  }

  // طباعة النتيجة باستخدام String Interpolation
  print("\n--- Student Result ---");
  print("Student: $name");
  print("Score: $score");
  print("Grade: $grade");
}
```
