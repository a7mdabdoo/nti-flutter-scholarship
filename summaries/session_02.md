## 1. ما هي البرمجة؟
البرمجة هي أحد فروع العلوم الهندسية، هدفها الأساسي هو **حل المشكلات** وأتمتة المهام اليومية باستخدام الحاسوب.
* **كيف حلت البرمجة مشاكل العالم؟**
  - **الطب:** أجهزة الأشعة، تشخيص الأمراض، وإدارة المستشفيات.
  - **التعليم:** المنصات التعليمية والتعلم عن بُعد.
  - **التواصل والتجارة:** تطبيقات المحادثات، والتجارة الإلكترونية، والدفع الإلكتروني.

---

| المجال | التخصص | الوصف |

| **6. الأمن السيبراني** | Cybersecurity | حماية الشبكات والأنظمة والبيانات من الاختراق |

---

## 3. لماذا نستخدم لغات البرمجة؟
* **الآلة (Computer):** لا تفهم سوى **اللغة الثنائية (Binary Code)** المكونة من `0` و `1`، وتتميز بالسرعة الفائقة جداً مقارنة بالإنسان.
* **لغة البرمجة:** هي الوسيلة التي نكتب بها أوامر يفهمها الإنسان، ثم يقوم **المترجم (Compiler)** بتحويلها إلى أصفار وآحاد تفهمها الآلة.

---

## 4. ما هو Dart SDK؟
* هو اختصار لـ **Software Development Kit** أي حزمة تطوير البرمجيات الخاصة بلغة Dart، وتحتوي على:
  1. **المترجم (Dart Compiler):** لتحويل الكود إلى لغة الآلة.
  2. **المكتبات الأساسية (Core Libraries):** مثل مكتبة الإدخال والإخراج `dart:io`.
  3. **أدوات المطورين:** لفحص الأخطاء وتنسيق الكود.

---

## 5. المتغيرات وأنواع اللغات

| نوع اللغة | طريقة التعامل مع المتغيرات | أمثلة |
|:---|:---|:---|
| **Static Languages** | يجب تحديد نوع المتغير مسبقاً قبل التشغيل ولا يتغير | C++, Java |
| **Dynamic Languages** | لا يشترط كتابة النوع، ويتحدد تلقائياً وقت التشغيل | Python, JS |
| **لغة Dart** | تجمع بين القوة والمرونة: تدعم تحديد النوع صراحة (`int`, `String`, `double`, `bool`) وتدعم استنتاج النوع تلقائياً عبر `var` | Dart |

</div>

```dart
void main() {
  // Explicit types
  String name = 'Ahmed';
  int age = 19;
  double gpa = 3.5;
  bool isStudent = true;

  // Type inference using var
  var country = 'Egypt';
  print('$name from $country, Age: $age, GPA: $gpa, Student: $isStudent');
}
```

## 6. المعاملات في لغة Dart

| النوع | المعاملات | الوظيفة |
|:---|:---|:---|
| **الحسابية (Arithmetic)** | `+`, `-`, `*`, `/`, `~/`, `%` | الجمع، الطرح، الضرب، القسمة، القسمة الصحيحة، وباقي القسمة |
| **التعيين (Assignment)** | `=`, `+=`, `-=`, `*=`, `/=` | إسناد وتعديل القيمة، مثلاً `x += 5` تعني `x = x + 5` |
| **المقارنة (Comparison)** | `==`, `!=`, `>`, `<`, `>=`, `<=` | المقارنة بين قيمتين والنتيجة دائماً `true` أو `false` |
| **المنطقية (Logical)** | `&&`, `\|\|`, `!` | الربط بين الشروط: `&&` (و)، `\|\|` (أو)، `!` (عكس الشرط) |

## 7. جمل التحكم والشروط: Conditions

تُستخدم لاتخاذ القرارات في البرنامج بناءً على تحقق شرط معين:

</div>

```dart
void main() {
  int score = 88;

  if (score >= 85) {
    print('Grade: A');
  } else if (score >= 75) {
    print('Grade: B');
  } else if (score >= 50) {
    print('Grade: C');
  } else {
    print('Grade: F');
  }
}
```

## 8. طريقة الإدخال في Dart: User Input

لاستقبال قيم من المستخدم في الـ Terminal (المقابل لـ `cin` في C++):
1. استيراد مكتبة `dart:io` في أعلى الملف.
2. قراءة النص باستخدام `stdin.readLineSync()!`.
3. تحويل النص إلى رقم باستخدام `int.parse` أو `double.parse`.

</div>

```dart
import 'dart:io';

void main() {
  stdout.write('Enter your name: ');
  String name = stdin.readLineSync()!;

  stdout.write('Enter your score: ');
  double score = double.parse(stdin.readLineSync()!);

  print('Welcome $name, your score is $score');
}
```
