## 1. ما هو Flutter؟ (What is Flutter?)

**Flutter** هو إطار عمل (UI Software Development Kit) مفتوح المصدر تم تطويره بواسطة شركة **Google** لبناء تطبيقات متعددة المنصات بكود برمجي واحد.

* **Cross-Platform (متعدد المنصات):**
  - باستخدام **Single Codebase** (نفس الكود المكتوب بلغة **Dart**)، تستطيع بناء وتصدير التطبيق ليعمل على:
    - 📱 **Mobile:** Android & iOS
    - 💻 **Desktop:** Windows, macOS, Linux
    - 🌐 **Web:** Modern Web Browsers
* **الميزة الأساسية:** توفير هائل في الوقت والمجهود وتكلفة التطوير، فبدلاً من توظيف فريقين منفصلين (فريق للأندرويد بلغة Kotlin/Java وفريق للـ iOS بلغة Swift)، يقوم مطور Flutter بالعمل على كلا النظامين معاً بنفس الأداء القوي.

## 2. دورة حياة تطوير البرمجيات (SDLC)
### Software Development Life Cycle

هي المنهجية والمراحل المنظمة التي يمر بها أي مشروع برمجي منذ كونه مجرد فكرة حتى إطلاقه وصيانته وتطويره.

#### 🔄 مسار مراحل المشروع (Project Workflow):
> **1️⃣ Requirements** ➔ **2️⃣ Analysis & Planning** ➔ **3️⃣ Design** ➔ **4️⃣ Implementation** ➔ **5️⃣ Testing** ➔ **6️⃣ Deployment** ➔ **7️⃣ Maintenance** 🔄

---

#### 📋 تفاصيل المراحل السبعة:

| # | المرحلة (Phase) | الاسم بالعربي | الشرح والتفاصيل العملية |
|:---:|:---|:---|:---|
| **1** | **Requirements Gathering** | جمع المتطلبات | الاجتماع مع العميل (Client / Stakeholders) لفهم فكرة البرنامج بالتفصيل، وتحديد كل ما يحتاجه التطبيق ومستخدموه. |
| **2** | **Analysis & Planning** | التحليل والتخطيط | دراسة الجدوى التقنية: هل المطلوب قابل للتنفيذ واقعياً؟ وبناءً على التحليل يتم وضع خطة زمنية وميزانية للمشروع وتحديد التقنيات المستخدمة. |
| **3** | **Design** | التصميم | يشمل تصميم الواجهات وتجربة المستخدم (**UI/UX**) باستخدام أدوات مثل Figma، وتصميم معمارية النظام وهيكل البيانات. |
| **4** | **Implementation** | التطوير والبرمجة | البداية الفعلية لكتابة الكود وتحويل التصاميم والمتطلبات إلى شاشات وميزات حقيقية تعمل. |
| **5** | **Testing** | فحص الجودة والاختبار | اختبار البرنامج للتأكد من خلوه من الأخطاء (Bugs/Crashes) ومطابقته لكافة المتطلبات المتفق عليها قبل التسليم. |
| **6** | **Deployment** | النشر والإطلاق | نشر التطبيق ليصبح متاحاً للمستخدمين (رفعه على Google Play و Apple App Store ونشر الـ Backend/Server). |
| **7** | **Maintenance & Support** | الصيانة والدعم الفني | متابعة التطبيق بعد النشر، وإصلاح الأخطاء التي تظهر مع الاستخدام الحقيقي، وإرسال تحديثات وإضافات جديدة. |

## 3. نظام عمل البرامج (Program System)
### نموذج معالجة البيانات: (Input ➔ Process ➔ Output)

أي نظام برمجي يعتمد على دورة أساسية ثلاثية:

> **📥 Input (المدخلات)** ➔ **⚙️ Process (المعالجة والعمليات)** ➔ **📤 Output (المخرجات)**

| الركن | الاسم | الوظيفة في البرنامج | أمثلة عملية |
|:---:|:---|:---|:---|
| **1** | **Input** | المدخلات | البيانات الخام التي يستقبلها البرنامج لتخزينها في المتغيرات (**Variables**)، أو مدخلات المستخدم من الحقول والأزرار. |
| **2** | **Process** | المعالجة | العمليات التي تُجرى على المتغيرات للوصول للنتيجة: <br> • **عمليات حسابية** (Arithmetic: `+`, `-`, `*`, `/`) <br> • **شروط منطقية** (Conditions: `if`, `switch`) <br> • **حلقات تكرارية** (Loops: `for`, `while`) <br> • **دوال منطق العمل** (Functions) |
| **3** | **Output** | المخرجات | النتيجة النهائية بعد المعالجة، وتظهر كقيم أو نصوص على الشاشة للمستخدم، أو تُحفظ في قاعدة بيانات. |

## 4. ربط المفاهيم بلغة Dart

مثال برمجي يوضح فكرة الـ **Input -> Process -> Output**:

```dart
void main() {
  // 1. Input: متغيرات تمثل المدخلات
  double itemPrice = 100.0;
  double taxRate = 0.14; // ضريبة 14%
  bool hasDiscountCoupon = true;

  // 2. Process: عمليات حسابية وشروط منطقية (المعالجة)
  double total = itemPrice + (itemPrice * taxRate);

  if (hasDiscountCoupon) {
    total = total - 10.0; // خصم 10 جنيه في حالة وجود كوبون
  }

  // 3. Output: إخراج النتيجة النهائية
  print("السعر النهائي المطلوب دفعه: $total EGP");
}
```

## 5. ملخص سريع لأهم النقاط (Key Takeaways)
* ✅ **Flutter:** إطار عمل من Google، لغته هي **Dart**، ميزته الأساسية إنه **Cross-Platform** (كود واحد لكل المنصات).
* ✅ **SDLC:** سبع مراحل متتابعة تبدأ بجمع المتطلبات (Requirements) وتنتهي بالصيانة والتطوير (Maintenance).
* ✅ **هيكل أي برنامج:**
  `Input ➔ Process ➔ Output`  
  المدخلات تُخزن في متغيرات، تُعالج عبر العمليات والشروط واللوبس، وتُعرض للمستخدم كمخرجات.
