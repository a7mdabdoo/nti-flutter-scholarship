# 📱 ملخص الجلسة الأولى (Session 01)

> **المحاضر:** م / إبراهيم حمادة مسعد

---

### 1. ما هو فلاتر (Flutter)؟
* هو تقنية من شركة **Google** لبناء تطبيقات متعددة المنصات (**Cross-Platform**).
* **الفكرة الأساسية:** بكود واحد فقط (**Single Codebase**) تقدر تشغله على:
  - 📱 موبايل (Android & iOS)
  - 💻 كمبيوتر (Windows, macOS, Linux)
  - 🌐 ويب (Web)

---

### 2. دورة حياة تطوير البرمجيات (SDLC)
المراحل السبعة اللي بيمر بيها أي برنامج من البداية للنهاية:

| # | المرحلة | الشرح باختصار |
|:---:|:---|:---|
| **1** | **Requirements (المتطلبات)** | الجلوس مع العميل لمعرفة كل المطلوب في البرنامج. |
| **2** | **Analysis & Planning (التحليل والتخطيط)** | دراسة إمكانية تنفيذ المطلوب ووضع خطة كاملة للبرنامج. |
| **3** | **Design (التصميم)** | تصميم واجهات وشكل البرنامج. |
| **4** | **Implementation (التنفيذ)** | بداية كتابة الكود الفعلي للبرنامج. |
| **5** | **Testing (الاختبار)** | فحص البرنامج والتأكد من خلوه من أي أخطاء. |
| **6** | **Deployment (النشر)** | رفع البرنامج على المتاجر (Google Play / App Store). |
| **7** | **Maintenance (الصيانة)** | متابعة وصيانة البرنامج بعد النشر وحل أي مشاكل تظهر. |

---

### 3. نظام عمل البرامج (Program System)
أي برنامج بيعتمد على 3 خطوات أساسية:

> **المدخلات (Input)** ➔ **المعالجة (Process)** ➔ **المخرجات (Output)**

1. **المدخلات (Input):** البيانات اللي البرنامج بيستقبلها، زي المتغيرات (**Variables**).
2. **المعالجة (Process):** العمليات اللي بتتم على المتغيرات، مثل:
   - العمليات الحسابية (`+`, `-`, `*`, `/`)
   - الشروط والعمليات المنطقية (`if`, `switch`)
   - الحلقات التكرارية (Loops)
3. **المخرجات (Output):** استخراج النواتج والقيم النهائية وعرضها للمستخدم.

---

### 4. مثال بلغة Dart

<div dir="ltr">

```dart
void main() {
  // 1. Input (مدخلات)
  int price = 100;
  int tax = 14;

  // 2. Process (معالجة)
  int total = price + tax;

  // 3. Output (مخرجات)
  print("Total: $total");
}
```
