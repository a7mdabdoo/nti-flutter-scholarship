## 1. ما هو فلاتر (Flutter)؟

يُعد **Flutter** إطار عمل مفتوح المصدر (UI SDK) طوّرته شركة **Google** لبناء واجهات وتطبيقات متعددة المنصات بكود برمجي واحد.

* **مفهوم تعدد المنصات (Cross-Platform):**
  باستخدام كود مصدري واحد (**Single Codebase**) مكتوب بلغة **Dart**، يمكن بناء ونشر التطبيق ليعمل على:
  - 📱 **الموبايل:** نظامي Android و iOS.
  - 💻 **الكمبيوتر:** أنظمة Windows و macOS و Linux.
  - 🌐 **الويب:** متصفحات الإنترنت المختلفة (Web Browsers).

* **الفائدة الأساسية:**
  توفير كبير في الوقت والتكلفة والمجهود؛ فبدلاً من بناء تطبيقين منفصلين (واحد للأندرويد بلغة Java/Kotlin وآخر للآيفون بلغة Swift)، يقوم مطور Flutter بالعمل على كلا النظامين معاً بنفس الأداء والكفاءة العالية.

## 2. دورة حياة تطوير البرمجيات (SDLC)

تُعرف بـ **Software Development Life Cycle**، وهي المنهجية والمراحل المنظمة التي يمر بها أي مشروع برمجي منذ كونه فكرة وحتى نشره وصيانته:

### 📋 جدول مراحل الـ SDLC:

| # | المرحلة بالإنجليزية | الاسم بالعربي | الشرح وما يتم إنجازه في المرحلة |
|:---:|:---|:---|:---|
| **1** | **Requirements Gathering** | جمع المتطلبات | الجلوس مع العميل والاجتماع به لفهم متطلبات البرنامج بدقة وتحديد احتياجات المستخدمين. |
| **2** | **Analysis & Planning** | التحليل والتخطيط | دراسة إمكانية تنفيذ المطلوب تقنياً وعلى أرض الواقع، ووضع خطة زمنية وميزانية للمشروع. |
| **3** | **Design** | التصميم | تصميم واجهات المستخدم (**UI/UX**) باستخدام Figma، وتصميم هيكلية النظام وقواعد البيانات. |
| **4** | **Implementation** | التطوير والبرمجة | بداية كتابة الكود الفعلي للبرنامج وتحويل التصاميم إلى نظام حقيقي قابل للتشغيل. |
| **5** | **Testing** | الاختبار وفحص الجودة | فحص واختبار البرنامج للتأكد من خلوه من الأخطاء (Bugs) ومطابقته لكافة المتطلبات. |
| **6** | **Deployment** | النشر والإطلاق | نشر التطبيق ليصبح متاحاً للجمهور (رفعه على Google Play و Apple App Store و السيرفرات). |
| **7** | **Maintenance** | الصيانة والتطوير | متابعة البرنامج بعد الإطلاق، وحل أي مشكلات تظهر، وإرسال تحديثات وإضافات جديدة دورياً. |

## 3. نظام عمل البرامج (Input - Process - Output)

يعتمد أي نظام برمجي في الحاسب على دورة عمل ثلاثية ثابتة:

### 📋 تفاصيل أركان النظام:

| الركن | المفهوم | التعريف والوظيفة | أمثلة تطبيقية |
|:---:|:---|:---|:---|
| **1** | **المدخلات (Input)** | البيانات الخام التي يستقبلها البرنامج ويخزنها في متغيرات (**Variables**). | نصوص من المستخدم، أرقام، ضغطات أزرار، بيانات قادمة من API. |
| **2** | **المعالجة (Process)** | العمليات المنطقية والحسابية التي تُجرى على المتغيرات لإنتاج الحل. | • عمليات حسابية (`+`, `-`, `*`, `/`)<br>• شروط منطقية (`if`, `switch`)<br>• تكرار ولوبس (`for`, `while`)<br>• دوال برمجية (Functions) |
| **3** | **المخرجات (Output)** | النواتج والقيم النهائية بعد معالجة البيانات وتجهيزها. | نصوص وأرقام معروضة على الشاشة، رسائل تأكيد، أو حفظ في قاعدة بيانات. |

## 4. تطبيق المفاهيم برمجياً بلغة Dart

المثال التالي يوضح تطبيق دورة (المدخلات ➔ المعالجة ➔ المخرجات):

<div dir="ltr">

```dart
void main() {
  // 1. Input: متغيرات تمثل المدخلات
  double itemPrice = 100.0;
  double taxRate = 0.14; // نسبة الضريبة 14%
  bool hasDiscountCoupon = true;

  // 2. Process: المعالجة عبر العمليات الحسابية والشروط
  double total = itemPrice + (itemPrice * taxRate);

  if (hasDiscountCoupon) {
    total = total - 10.0; // خصم 10 جنيه عند وجود كوبون
  }

  // 3. Output: إخراج وطباعة النتيجة للمستخدم
  print("السعر النهائي المطلوب دفعه: $total EGP");
}
```
